# Design knowledge base

Seed version: **2026-08**. Regenerated by `refresh-design-knowledge` and by step 2 of `generate-themes`.

| File | Domain | Read it when |
|---|---|---|
| `01-design-tokens.md` | Token formats, DTCG, Style Dictionary, platform mapping | Always — it defines the output contract |
| `02-color.md` | OKLCH, gamut, ramps, contrast, light/dark | Always |
| `03-typography.md` | Variable fonts, scales, pairing, font sources | Always |
| `04-aesthetics.md` | The direction catalogue — 12 named aesthetics with parameters | Always — this is your assigned direction |
| `05-css-platform.md` | Tailwind v4, container queries, view transitions, modern CSS | When writing CSS or the preview |
| `06-motion.md` | Motion principles, timing, libraries, native animation | When the direction is motion-forward |
| `07-component-systems.md` | shadcn/ui, Radix, Base UI, NativeWind, Tamagui | When applying a theme to a codebase |
| `08-logos-graphics.md` | SVG logo construction, favicons, procedural graphics, icons | When making brand assets |
| `09-mobile.md` | iOS HIG, Material 3 Expressive, device frames | When designing the mobile surface |
| `10-accessibility.md` | WCAG 2.2, targets, focus, motion preferences | Always |
| `11-native-platform.md` | React Native / Expo constraints: units, shadows, blur, fonts, config | Always when the target platforms include native — required, not optional |
| `12-asset-tooling.md` | Asset tooling, licensing, external services | Before generating brand assets, avatars, or imagery |

A theme-designer typically reads `02`, `03`, `04` (its own direction only), `08`, and `10` — plus `11` and `09` whenever native is a target platform. Reading all twelve wastes context.

`brand-asset-designer` reads `08`, `06`, `11`, and `12` — not the full set.
